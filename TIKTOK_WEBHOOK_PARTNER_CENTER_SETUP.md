# TikTok Shop Partner Center - Webhook Registration (Quick Reference)\n\n## 🎯 Pre-Requisites\n\n✅ Webhook Edge Function deployed: **tiktok-webhook** (v1)\n✅ Environment variable set: `TIKTOK_APP_SECRET` in Supabase\n✅ You have access to TikTok Shop Partner Center (seller account)\n\n---\n\n## 📍 Step-by-Step: Register Webhook in TikTok Partner Center\n\n### Step 1: Navigate to Partner Center\n```\nGo to: https://seller.tiktokshop.com/partner/\n(or: https://seller-us.tiktokshop.com if in US)\n\nLogin with your seller account credentials\n```\n\n### Step 2: Find Webhook Settings\n\nPath may vary by region/version. Try:\n\n**Option A - Settings → Apps:**\n```\nLeft Menu → Settings → Apps & Extensions → Your App Name\n                     → Webhooks (or Webhook Settings)\n```\n\n**Option B - Integrated Services:**\n```\nLeft Menu → Integrated Services → Webhooks\n```\n\n**Option C - Developer Settings:**\n```\nLeft Menu → Developer Settings → Webhooks\n```\n\n*If you can't find it, search \"webhook\" in Partner Center search bar*\n\n### Step 3: Add New Webhook Endpoint\n\nLook for button: **\"Add Webhook\"** or **\"Register Webhook\"** or **\"New Endpoint\"**\n\n### Step 4: Fill in Webhook Details\n\n#### Field 1: Webhook URL (Endpoint URL)\n```\nhttps://dtttdgdkhayzchmfptjt.supabase.co/functions/v1/tiktok-webhook\n```\n\n#### Field 2: Event Type / Webhook Type\n```\nSelect: ORDER_STATUS_CHANGE\n(or: order.status_updated / order_status_change depending on UI)\n```\n\n**Why this event?**\n- Triggers when customer payment status changes\n- Triggers when order ships/delivery updates\n- Triggers when order is marked complete/cancelled\n- Most critical events for inventory & fulfillment sync\n\n#### Field 3: Select Shops (if applicable)\n```\n☑ Select the shop(s) to monitor\n(or: \"All shops\" if monitoring all)\n```\n\n#### Field 4: Version / API Version\n```\nSelect: v2 (or latest available)\n```\n\n#### Field 5: Active / Enable\n```\n☑ Enable / Active (make sure checkbox is checked)\n```\n\n### Step 5: Save / Confirm\n\nClick: **\"Save\"** or **\"Register\"** or **\"Confirm\"**\n\n**Expected result:** \n```\n✅ \"Webhook registered successfully\" or similar message\n```\n\n---\n\n## 🧪 TikTok Will Send a Test Webhook\n\nAfter registration, TikTok automatically sends a **test webhook** to verify your endpoint:\n\n```\nPOST https://dtttdgdkhayzchmfptjt.supabase.co/functions/v1/tiktok-webhook\nHeaders:\n  x-tiktok-timestamp: [test_timestamp]\n  x-tiktok-sign: [valid_test_signature]\nBody:\n  {\"type\": \"ORDER_STATUS_CHANGE\", \"data\": {...}}\n```\n\n**Our function will:**\n1. ✅ Verify the signature\n2. ✅ Parse the test payload\n3. ✅ Return `{\"code\": \"200\", \"message\": \"Received\"}`\n\n**Result:** Partner Center shows ✅ **\"Test Passed\"** or **\"Connected\"**\n\n---\n\n## ✅ Verify Webhook Registration\n\n### In Partner Center:\n1. Go back to **Webhooks** section\n2. Find your newly registered webhook in the list\n3. Status should show: **\"Active\"** or **\"Enabled\"**\n4. Last delivery timestamp should show recent test\n\n### Webhook Delivery Logs:\n1. Click on your webhook entry\n2. View **\"Delivery History\"** or **\"Event Logs\"**\n3. Should show recent successful deliveries (green checkmarks)\n\n---\n\n## 🔍 Monitor Live Webhook Events\n\nOnce live orders come in:\n\n### In Partner Center Webhook Logs:\n- Each order status change shows a log entry\n- Status: **\"Success\"** = our function returned 200 OK\n- Timestamp: when webhook was delivered\n- Payload: the order data included\n\n### In Supabase Edge Function Logs:\n```\nSupabase Dashboard → Functions → tiktok-webhook → Logs\n\nYou'll see:\n  \"TikTok webhook received: ORDER_STATUS_CHANGE\"\n  \"Processing order 123456789: COMPLETED -> shipped\"\n  \"✓ Updated order 123456789 to shipped\"\n```\n\n---\n\n## ⚠️ Troubleshooting: Webhook Not Registering\n\n### Problem: 404 Not Found\n**Cause:** URL is incorrect or endpoint unreachable\n**Solution:**\n- Verify URL: `https://dtttdgdkhayzchmfptjt.supabase.co/functions/v1/tiktok-webhook`\n- Test in browser: should show CORS error or empty response (that's OK)\n- Check Supabase function is deployed: `supabase functions list`\n\n### Problem: \"Invalid Webhook URL\" error\n**Cause:** URL format issue or Partner Center validation\n**Solution:**\n- Ensure URL starts with `https://` (not http)\n- No spaces in URL\n- No trailing slashes\n- Copy-paste to avoid typos\n\n### Problem: Signature Verification Failed (403)\n**Cause:** Wrong `TIKTOK_APP_SECRET` in Supabase\n**Solution:**\n1. In TikTok Partner Center, find your App Settings\n2. Copy the exact **App Secret** (usually starts with specific prefix)\n3. In Supabase Dashboard → Edge Functions → Secrets\n4. Paste as `TIKTOK_APP_SECRET`\n5. Redeploy: `supabase functions deploy tiktok-webhook`\n\n---\n\n## 🚀 After Webhook is Active\n\n### What Happens Next:\n\n1. **Real order placed on TikTok Shop**\n   ```\n   ↓\n   TikTok detects status change (payment received, etc.)\n   ↓\n   TikTok sends webhook to our endpoint\n   ↓\n   Our function verifies signature & updates orders table\n   ↓\n   ERP shows updated order status in seconds ✓\n   ```\n\n2. **No More Polling**\n   - Old method: `tiktok-sync-orders` polls every 5+ minutes\n   - New method: Webhook pushes updates immediately\n   - Reduces API calls & latency\n\n3. **Logs appear in:**\n   - TikTok Partner Center → Webhooks → Logs (delivery confirmations)\n   - Supabase Functions → Logs (processing details)\n   - ERP UI → Orders page (updated status)\n\n---\n\n## 📋 Configuration Checklist\n\n- [ ] Logged into TikTok Partner Center\n- [ ] Found Webhooks/Integrated Services section\n- [ ] Clicked \"Add/Register Webhook\"\n- [ ] Entered URL: `https://dtttdgdkhayzchmfptjt.supabase.co/functions/v1/tiktok-webhook`\n- [ ] Selected Event Type: `ORDER_STATUS_CHANGE`\n- [ ] Selected shop(s) to monitor\n- [ ] Checked \"Active/Enabled\"\n- [ ] Clicked \"Save/Confirm\"\n- [ ] Saw ✅ \"Registration successful\" message\n- [ ] Webhook appears in list with \"Active\" status\n- [ ] Test webhook was sent (check delivery logs)\n- [ ] Saw ✅ test passed or \"Connected\"\n- [ ] Place test order in TikTok Shop\n- [ ] Check Supabase logs show webhook processing\n- [ ] Verify order status updated in ERP\n\n---\n\n## 💡 Tips\n\n- **Keep this URL bookmarked:** `https://seller.tiktokshop.com/partner/`\n- **Webhook URL never changes** (unless you redeploy to different Supabase project)\n- **TIKTOK_APP_SECRET must stay secret** (don't share or commit to git)\n- **Monitor logs regularly** to catch any delivery failures early\n- **Test with small order first** before relying on webhooks for critical operations\n\n---\n\n## Need Help?\n\n**Webhook not triggering?**\n1.
